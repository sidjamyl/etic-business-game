# ETIC Business Game

Cadrage du business game du mini-projet d'intégration du club ETIC.

Lire [product.md](product.md) : vision, mécaniques exprimées et questions encore ouvertes. Le document est un brouillon ; les recommandations de l'assistant restent à valider.

## Reprendre avec un agent

Demander : « Utilise GrillMe sur product.md. Reprends les questions Q6–Q11 ouvertes de la section 15, puis approfondis les branches qui en dépendent. Mets à jour le document avec mes réponses. »

Les skills de Matt Pocock nécessaires à cet entretien sont inclus dans [.agents/skills](.agents/skills) : `grill-me`, `grilling`, `grill-with-docs` et `domain-modeling` avec leurs fichiers de référence. Pour un agent qui ne les découvre pas automatiquement, lui demander de lire les SKILL.md correspondants.

L'origine, la version et la licence de ces copies sont indiquées dans [THIRD_PARTY.md](THIRD_PARTY.md).
